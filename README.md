# android-sec-lab

Execute the following commands on kali
```
git clone https://github.com/easyhack1ng/android-sec-lab.git
cd android-sec-lab/EasyAndro/
sudo ./setup.sh
```

✅ 원클릭 자동화 기능:
1. Python 및 Frida 호환 버전 자동 설정 (Objection/Frida 실행 환경 구성)
2. Flutter 앱 → 프록시 설정 + Reflutter + 서명 + Frida SSL 언피닝
3. 일반 앱 → 프록시 설정 + Frida SSL 언피닝
4. 루팅 및 위변조 탐지 실행 및 결과 출력

✅ One-click automation for:
1. Auto setup of compatible Python & Frida version for Objection/Frida
2. Flutter app → Proxy setup + Reflutter + Signing + Frida SSL Unpinning
3. Non-Flutter app → Proxy setup + Frida SSL Unpinning
4. Rooting & Tampering detection with result output
